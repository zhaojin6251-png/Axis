# 架构决策记录

本目录保存 Regression Agent 的架构决策记录（Architecture Decision Records，ADR）。

ADR 用于记录影响多个模块、后续难以低成本撤销的决策。实现细节、短期任务和产品需求不应写入 ADR。

## 状态约定

- `提议中`：正在评审，尚未成为实现约束。
- `已接受`：评审通过，后续实现应遵守该决策。
- `已取代`：由新的 ADR 替代，但保留历史背景。
- `已废弃`：不再适用，且没有直接替代决策。

## 维护规则

1. ADR 一旦被接受，不直接改写其核心决策；需要改变时新增 ADR，并将旧 ADR 标记为“已取代”。
2. 可以补充不改变原意的链接、勘误和实现状态。
3. 每份 ADR 至少说明背景、决策、后果和未解决问题。
